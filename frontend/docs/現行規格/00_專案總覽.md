## 一句話定位

一套以 human-in-the-loop agentic 編排為核心、內建 MLOps 資料飛輪的閉環照護事件系統，影像感知（跌倒偵測＋環境安全評分）只是輸入之一。差異化不在感知模型，而在三支柱：**Agentic 事件編排、抗警報疲乏的 HITL 中控台、MLOps 資料飛輪與模型治理**。

前端最高原則：**降低值班人員認知負荷**（每張卡片一個視覺重點、紅色只給真正危險、不做花俏動畫）。

## 使用者與角色

| 角色 | 說明 | 權限重點 |
|------|------|---------|
| staff（值班照護員） | 只在真的需要時被通知，能一鍵接手／結案／標記誤報 | 看不到：設定、系統、MLOps 面板、Debug 監控、Agent 決策測試集／成本模型 |
| admin（機構管理者） | 掌握統計、誤報率、時效、稽核紀錄、模型治理 | 全部可見可操作 |

## MVP 範圍（本期做 / 不做）

**本期做**：影像串流接入、姿態＋追蹤＋規則初篩（YOLO）、冷卻機制、VLM 跌倒複判、事件分級與信心分數、中控台人工複判、Agent 派工與逾時升級、儀表板、事件片段保存、Web Push、環境安全定時評分、異常提醒、Hard Negative Pool、YOLO 效能監控、MLflow、固定測試集、MLOps 面板。

**本期不做**：辨識跌倒者身份、通知家屬、醫療嚴重性判定、支援所有監視器廠牌、LINE Bot、YOLO fine-tune 實跑（只收資料）。

**未來預留接口**：自動 fine-tune pipeline、A/B Testing、風險預測、照護 Copilot（RAG）、雲端／邊緣部署、去識別化。

## 技術堆疊（前端）

Vite + React 18 + TypeScript（已建立，勿重建）、Tailwind CSS v4 + CSS variables tokens、react-router v6、Recharts、Noto Sans TC。語言一律繁體中文（台灣用語）。細節與四條鐵律見 `CLAUDE.md`。

後端（對接用，非前端實作）：FastAPI + PostgreSQL + Kafka + 本地 VLM（Qwen2.5-VL）+ MLflow / ClearML，Docker Compose。
