## B. ⚠ 與 CLAUDE.md（最高權威）的衝突（需組長／團隊拍板）

CLAUDE.md 目前內容比後端實作舊，以下兩點**不建議我逕自改**（CLAUDE.md 規定衝突時以它為準、要先問），列出供你決定是否更新：

1. **事件狀態型別**：CLAUDE.md 的 `EventStatus` 與 `STATUS_LABEL` 含 `ESCALATED / 已升級`。若跟隨後端三態，前端狀態型別、首頁與事件中心的「已升級」篩選標籤、逾時升級 UI 都要調整。
   - 建議做法（待確認）：型別保留 ESCALATED 但標為「規格預留、後端暫未提供」，UI 暫不顯示已升級篩選與自動升級追蹤，等後端補上再開；或直接對齊三態＋verdict。二選一由組長定。
2. **登入方式**：CLAUDE.md 把 emailOtp 列「本期實作」、employeePassword 列空殼。後端實際是帳號密碼。建議把 `AUTH_MODE` 切到帳號密碼路徑、emailOtp 降為預留。**此項截至 2026-07-11 比對 repo 實際內容，仍未變更，見 F 段。**

> 待你決定後，我再依指示更新 CLAUDE.md（不會自行動它）。
