# 01 IA 導覽架構（現行）

> 來源：`Fulilian_IA資訊架構_v1.md` v1.0（結構源頭，內容照現行結論保留）。
> admin／staff 共用同一套選單，靠權限隱藏節點，不做兩套選單。
> 標色：🟩 本期 MVP　⬜ 本期不做（僅佔位預留入口）　🔒 需 admin 權限

## 頂層導覽（9 大類）

```
1. Home 總覽儀表板 🟩
2. 即時監控 Live Monitoring 🟩
3. 事件中心 Event Center 🟩
4. 環境安全 Environmental Safety 🟩
5. Agent 洞察 Agent Insights 🟩   ← 支柱一：Agentic 編排
6. MLOps 面板 Data Flywheel 🟩🔒  ← 支柱三：資料飛輪與治理
7. 歷史紀錄 History 🟩
8. 設定 Configuration 🔒
9. 系統 System 🔒
```

第 3、4 類是感知輸入的結果呈現；第 5、6 類把差異化工程支柱獨立成看得見的頁面，方便期末展示。

## 各類節點

### 1. Home 總覽儀表板 🟩
待處理事件卡、今日誤報率卡、環境安全平均分卡、環境危險區域提示（點擊跳 4-3）、MLOps 健康度卡、點卡片快速跳轉對應清單頁。

### 2. 即時監控 🟩
| 節點 | 說明 |
|------|------|
| 2-1 攝影機清單 | 依區域分組列出，顯示上下線 |
| 2-2 即時畫面 | 單路即時串流（RTSP／WebCam） |
| 2-3 事件即時疊加 | 骨架關鍵點／追蹤框，疑似跌倒時標示 |
| 2-4 Debug 監控 🔒 | 規則初篩分數、冷卻狀態、Track ID，除錯用 |

### 3. 事件中心 🟩（中控台主戰場、HITL 核心）
| 節點 | 說明 |
|------|------|
| 3-1 事件清單（即時處理） | 填色膠囊篩狀態（已接手／已結案／誤報）／時間／區域；不含待處理、已升級-未接手（該兩態由首頁全螢幕警示與「需要行動」區專責，點首頁卡片可直達共用詳情頁） |
| 3-2 事件詳情 | 影片片段、VLM 結構化結果 |
| 3-3 接手／結案／誤報 | 一鍵標記；誤報時選類型（坐地／伸展／彎腰／攙扶／其他） |
| 3-4 派工與升級追蹤 | 通知對象、逾時倒數、是否自動升級 |
| 3-5 交班／事故紀錄草稿 | Agent 草擬，人工審核後存檔 |
| 3-6 冷卻與抑制紀錄 🔒 | COOLDOWN_SUPPRESSED／SUPPRESSED 清單 |
| 3-7 事件歷史查詢 | 近30天堆疊趨勢圖、安靜版篩選（已結案／誤報＋獨立「只顯示曾升級」快速切換，可疊加）、頁碼分頁、含處理耗時／信心／曾升級旗子；由原 7-1 移入，staff 可查 |

### 4. 環境安全 🟩
| 節點 | 說明 |
|------|------|
| 4-1 安全評分總覽 | 各攝影機最新總分卡，依等級標色 |
| 4-2 評分詳情 | 分項分數＋VLM 描述、風險因子 |
| 4-3 危險區域標示 | 標示「需注意」攝影機區域 |
| 4-4 評分趨勢 | 各攝影機評分歷史折線圖 |
| 4-5 異常提醒紀錄 | score_drop 超閾值觸發歷史 |

### 5. Agent 洞察 🟩（厚 agent 可見化，展示技術點 2/3/4/8/11）
| 節點 | 說明 |
|------|------|
| 5-1 推理軌跡檢視 | 單事件 observe→reason→act、調用工具與理由 |
| 5-2 不確定性路由紀錄 | 灰色信心（0.5–0.85）路由結果與理由 |
| 5-3 多事件 Triage 面板 | 並列派工順序與判斷理由 |
| 5-4 跨事件模式提醒 | 累積異常的複查／敏感度微調提案 |
| 5-5 決策黃金測試集儀表板 🔒 | 路由／派工／升級決策正確率 |
| 5-6 成本模型面板 🔒 | 每事件 LLM 呼叫次數／token／延遲／成本 |

### 6. MLOps 面板 🟩🔒
| 節點 | 說明 |
|------|------|
| 6-1 每日效能指標 | FP/Day、信心分數趨勢、VLM 推翻率 |
| 6-2 Hard Negative Pool 管理 | 清單／篩選／匯出 |
| 6-3 模型版本管理 | 版本、狀態、Recall／FPR／mAP 比較 |
| 6-4 Fine-tune 觸發入口 | 手動觸發（預留自動閾值開關） |
| 6-5 部署審核 Promote | 通過門檻後人工升格 Production |
| 6-6 版本回滾 | 一鍵切回上一版 |
| 6-7 固定測試集資訊（唯讀） | 組成與凍結狀態 |

### 7. 歷史紀錄 🟩（稽核／家屬查閱）
7-1 事件歷史、7-2 環境安全評分歷史、7-3 通報紀錄 🔒、7-4 影像片段下載（含保存期限標示）。
（原 7-1 事件歷史已移入「事件中心 → 歷史查詢」模式，見第 3 類；此處編號保留不重編以免破壞跨檔引用。）

### 8. 設定 🔒（僅 admin）
8-1 裝置／攝影機管理、8-2 區域（Zone）管理、8-3 值班表、8-4 長者歸戶、8-5 閾值與規則（冷卻 5 分／評分週期 15 分／異常閾值 15 分／信心路由 0.85 與 0.5）、8-6 通報管道、⬜ 8-7 LINE Bot（本期不做）。

### 9. 系統 🔒
9-1 系統資訊、9-2 帳號權限管理、9-3 系統監控、9-4 登出／重啟。

## 權限顯示邏輯（給前端 Track D）

- 單一路由表 + `role` 欄位控制節點顯示，**不要為 staff 另建一套路由**（降低維護成本）。
- staff 看不到：8 設定（全部）、9 系統（全部）、5-5／5-6、6 MLOps（全部）、2-4 Debug、7-3 通報紀錄。
- staff 可操作：2、3（除 3-6）、4、7（唯讀，除 7-3）。
- admin 全部可見可操作。
- Agent 洞察節點：目前灰階不可點，標「即將推出」（見 CLAUDE.md 權限規則）。
