## 通則（跨頁共用）

- **篩選樣式兩種、刻意差異化**：即時處理情境（首頁、事件中心）用**填色膠囊**便於快速掃視；回顧情境（歷史紀錄、HNP）用**安靜版**（無填色、選中加底線、只留中文、拿掉英文狀態碼）。此為刻意差異，非不一致。
- **分頁兩種**：即時推播頁（首頁、事件中心）用「頂部新事件提示條＋底部載入更多」；回顧頁（歷史紀錄）用靜態頁碼分頁。
- **篩選項目型式原則**：數量固定用 chip 攤開；數量會持續成長（如誤報類型）用下拉選單，避免版面隨資料跑版。
- **攝影機／區域選擇器（最終版）**：以**區域直接分組**（區域必填、永遠可靠），**無樓層收合層**；樓層降為選填顯示文字，有填才附加（如「鏡頭3・2F」）。demo 資料 company／樓層固定為 1，故 demo 版**不顯示樓層文字**，只呈現「區域・攝影機」。
  - 需精準到單一攝影機的頁（環境評分歷史 7-2、MLOps 每日效能 6-1）：區域收合→選到攝影機。
  - 只需到區域的頁（事件歷史 7-1、影像片段下載 7-4）：攤平區域清單，不下鑽攝影機。

## 7. 事件通知分級機制（二階段，通知管道已單一化）

- **階段一・系統判斷中（VLM 複審前）**：不推送文字，只在畫面角落顯示會動的小圖示＋數量角標；點角標展開輕量清單（僅列地點）。判非事件 → 角標 −1。
- **階段二・已確認需人工介入**：**直接觸發全螢幕警示（約佔螢幕 78% 寬）**，響應式改用相對單位（vw/vh/rem）＋`max-height: 90vh` 內部捲動＋flexbox 置中，50%／100%／150% 縮放皆須可讀。
- **通知管道單一化**：新的已確認事件**只走全螢幕警示**，不再有「彈窗＋列表」雙重出現；首頁列表只放已接手後狀態＋「已升級未接手」區。
- **警示按鈕改三顆**：**確認前往**（主要，`--success` 填色）／**通知人員前往**（次要，⚠ 後端端點未建，見 `04` 檔 #19）／**誤報**（低視覺權重，`--offline` 外框）。
- **誤點防線（兩層）**：①兩段式確認（第一次點擊出現「再按一次送出／取消」，第二次才呼叫 API）；②送出後 10 秒復原窗口（`ACK_TOAST_DURATION_MS = 10000`，提示「已接手・可復原」）。
- **誤報二次確認視窗**：內嵌事件影片，「確認誤報並關閉」預設反灰、影片播畢才解鎖；誤報類型必選（坐地／伸展／彎腰／攙扶／其他）、備註選填；送出呼叫 `POST /events/{id}/feedback` → SUPPRESSED 後警示才關閉。
- **「不可自動消失」唯一例外**：逾時升級時警示自動收合，事件落入首頁「需要行動」區。
- **逾時參數（程式碼常數現值）**：警示接手期限 90 秒（`CONFIRMED_ALERT_ACK_DEADLINE_MS`）、升級判定 60 秒（`ESCALATION_OVERDUE_MS`）、警示延遲跳出 10 秒（`CONFIRMED_ALERT_DELAY_MS`）。
- **多筆同時**：主警示卡維持單一焦點，下方窄佇列列其他已確認事件縮影，點佇列切換。
- 保留全螢幕與角標兩態區分的理由：若全部事件同一種呈現，全螢幕警示會失去「特別重要」的訊號意義。

## 7-補. 結案流程與草稿保護（新增，v1.43）

流程：事件發生 → 沒人接手 → 警示收合至儀表板「需要行動」 → 有人接手 → 顯示派人或自己前往 → 回來按「回報完成」→ 彈出結案視窗（**僅接手帳號可填**，他人按鈕反灰）→ 填處置紀錄 → 確認送出 → RESOLVED，卡片經推播自動移入「今日已結案」（畫面只反映狀態機，不自行搬移卡片）。

- 處置紀錄本期為**純手動輸入**；Agent 交班草稿（IA 3-5）待 Agent 洞察重啟後再接上。
- **草稿保護**：每 3 秒自動存 localStorage（key：`draft:{eventId}:{userId}`）；警示彈窗蓋上時底層視窗 CSS 隱藏不 unmount，回來可接續；附手動「儲存草稿」鈕與「已自動儲存 HH:mm」指示；送出成功即清除。
- 不做一鍵結案：結案為終態需留紀錄，必經視窗確認。
- 視窗內「已送醫／重大事件」勾選：送出後轉列管（見下一節），⚠ 後端未就緒前勾選值隨 payload 送出但不改變前端顯示。

## 11. 環境安全頁

- **關鍵：評分單位是「單一攝影機」，不是區域平均**。逐攝影機各自一張卡（如「走廊A・鏡頭1／2／3」）。「平均分」只出現在首頁 KPI。
- **總覽用不對稱版面**，依「是否需要注意」分兩層：
  - 需要注意（警示／危險）：大卡片置頂，含名稱、分數、等級標籤、主要風險摘要（取自 risk_factors）、走勢。
  - 正常（良好／注意）：一行式精簡列表，含名稱、狀態色點、趨勢箭頭（↑／↓／—）、分數。
- **走勢圖畫法**：折線＋危險閾值虛線（閾值下淡紅底）＋每日等級色點。卡片內再依等級分流：**危險**保留完整走勢圖＋一行文字（如「近 7 日降 43 分」）；**警示**改箭頭＋一行文字（如「較昨日降 8 分」）。
- **離線攝影機歸「需要注意」區塊**（不留在正常）：離線＝監控死角、急迫性等同需處理。呈現用中性灰色條、空心外框「離線」標籤、不顯示分數與走勢、改斷線圖示＋「中斷 N 小時 N 分」。全域統計新增「N 台離線」。
評分詳情頁：四向度進度條（各標分數／滿分／等級；地面地板30/通道暢通性30/潛在危險物品20/照明條件20，不含安全設施完整性，2026-07-12定案）＋整體描述＋風險因子標籤；同頁整合評分趨勢（4-4）與異常提醒紀錄（4-5）。
- ⚠ 本頁分數卡／走勢／向度全部依賴「有分數」的後端；後端目前只有二分文字判斷、無分數，7/12 前以假資料做畫面（見落差記錄）。
